# 有人值守称重窗口布局（ASCII）

本文档对 `MaterialClient/Views/AttendedWeighing/AttendedWeighingWindow.axaml` 做**模块化**布局说明，以 ASCII 示意。根容器为 `Grid`：`RowDefinitions="Auto,Auto,*,Auto"`，`ColumnDefinitions="*"`。

## 窗口外壳

```
+------------------------------------------------------------------+
|  Window（1366x768，无系统标题栏，白底）                           |
|  +------------------------------------------------------------+  |
|  | Panel                                                      |  |
|  |  +------------------------------------------------------+  |  |
|  |  | Grid（4 行 × 1 列）                                   |  |  |
|  |  |  Row0：标题栏                                         |  |  |
|  |  |  Row1：称重/横幅区                                    |  |  |
|  |  |  Row2：主工作区（* 占满剩余高度）                      |  |  |
|  |  |  Row3：状态栏                                         |  |  |
|  |  +------------------------------------------------------+  |  |
|  |  OverlayDialogHost（Ursa，全窗叠加对话框）              |  |
|  +------------------------------------------------------------+  |
+------------------------------------------------------------------+
```

## 模块 A — 标题栏（Grid.Row = 0）

容器：`Border`（`#4169E1`），`PointerPressed` 用于拖动窗口。

```
+------------------------------------------------------------------+
| [Logo 图 ~210x32]   [数据管理 系统设置 项目信息 …]     [─] [✕]   |
|                     （中间 StackPanel，负边距视觉左移）           |
|  Popup：DataManagementMenuPopup（锚定在栏下方，按需显示）       |
+------------------------------------------------------------------+
```

| 栅格列（Grid.Column） | 内容 |
| --- | --- |
| 0 | `Image` Logo |
| 1 | 横向 `StackPanel`：数据管理（弹出菜单）、系统设置、项目信息、数据同步、退出登录；导出（`IsVisible="False"`） |
| 2 | 最小化、关闭 |

## 维护说明

- 标题栏中间菜单使用较大负 `Margin` 做视觉左移，窗口宽度变化时可能需复核对齐。
- 横幅区状态文案与 `LoadingDotsAnimation` 同占 `Grid.Column="2"`，依赖负边距叠放，非独立列划分。
- 右侧边栏定义了 6 行，当前 XAML 中主要使用行 0–3；行 4–5 为结构占位，便于后续扩展或保持行定义一致。
