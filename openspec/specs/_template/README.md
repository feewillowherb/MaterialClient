# 规范模板

本目录包含创建新 OpenSpec 规范时使用的模板。

## 使用方式

1. 复制整个 `_template` 目录
2. 重命名为你的能力名称
3. 填写模板文件
4. 删除本说明 README

## 模板文件

- `spec.md` - 能力规范模板
- `tasks.md` - 实现任务模板
- `design.md` - 设计文档模板（可选，需要时创建）

## 后续步骤

创建规范后：

1. 与团队评审
2. 获得批准
3. 按 tasks.md 执行任务
4. 将规范标记为已实现
