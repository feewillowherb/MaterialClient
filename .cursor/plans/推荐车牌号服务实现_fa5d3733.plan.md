# 推荐车牌号服务实现计划

## 概述

创建一个单例服务 `RecommandPlateNumberService`，用于缓存车牌号并提供推荐功能。服务在应用启动时从数据库加载最新200条车牌号，并根据配置的最小字符差异数进行匹配推荐。

## 实现步骤

### 1. 更新 SystemSettings 配置类

**文件**: `MaterialClient.Common/Configuration/SystemSettings.cs`

在 `SystemSettings` 类中添加新属性：

```csharp
/// <summary>
/// 最小字符差异数（0-2），用于车牌号推荐匹配
/// </summary>
public int MinDiffCharCount { get; set; } = 0;
```

### 2. 创建 RecommandPlateNumberService

**文件**: `MaterialClient.Common/Providers/RecommandPlateNumberService.cs`

需要引用的命名空间：

```csharp
using System.Collections.Concurrent;
```

创建单例服务，包含以下功能：

- 私有字段：`_plateNumberCache` (volatile ConcurrentQueue<string>)，最大容量200
- 构造函数：注入 `IRepository<Waybill, long>`、`ILogger<RecommandPlateNumberService>` 和 `ISettingsService`
- `InitializeCacheAsync()`: 从数据库加载车牌号
  - 查询所有非空的 `PlateNumber`
  - 去重
  - 按 `AddDate` 降序排序
  - 取前200条
  - 创建新的 `ConcurrentQueue<string>`，填充数据
  - 使用 `Interlocked.Exchange` 或直接赋值（volatile）原子替换缓存引用
- `GetRecommandPlateNumber(string plateNumber)`: 推荐车牌号
  - 获取当前缓存的引用（volatile 读取）
  - 从 `SettingsService` 获取 `MinDiffCharCount` 配置
  - 遍历队列，计算字符差异数
  - 返回差异数 <= `MinDiffCharCount` 的第一个匹配项
  - 找到时记录日志
  - 未找到返回传入的原始参数 `plateNumber`

字符差异算法：比较两个字符串在相同位置上的不同字符数量（长度不同时，差异数 = 长度差 + 位置差异数）

### 6. 在 AttendedWeighingService 中集成推荐功能

**文件**: `MaterialClient.Common/Services/AttendedWeighingService.cs`

在 `AttendedWeighingService` 中：

1. **添加依赖注入**：

   - 在构造函数参数中添加 `RecommandPlateNumberService`（使用 `[AutoConstructor]` 特性自动注入）

2. **在 `OnPlateNumberRecognized` 方法中调用推荐接口**：

   - 在过滤"挂"字之后，调用 `_recommandPlateNumberService.GetRecommandPlateNumber(filteredPlateNumber)`
   - 使用推荐的车牌号替代原始识别到的车牌号
   - 如果推荐的车牌号与原始车牌号不同，记录日志

修改位置：`OnPlateNumberRecognized` 方法中，在 `PlateNumberValidator.FilterHangingCharacter` 之后：

```csharp
public void OnPlateNumberRecognized(string plateNumber)
{
    if (string.IsNullOrWhiteSpace(plateNumber)) return;

    // 过滤掉"挂"字（仅处理简体"挂"）
    var filteredPlateNumber = PlateNumberValidator.FilterHangingCharacter(plateNumber, _logger);

    // 如果过滤后为空，则不处理
    if (string.IsNullOrWhiteSpace(filteredPlateNumber)) return;

    // 获取推荐的车牌号
    var recommendedPlateNumber = _recommandPlateNumberService.GetRecommandPlateNumber(filteredPlateNumber);
    
    // 如果推荐的车牌号与原始不同，记录日志
    if (recommendedPlateNumber != filteredPlateNumber)
    {
        _logger?.LogInformation(
            "车牌号推荐匹配: 原始={OriginalPlate}, 推荐={RecommendedPlate}",
            filteredPlateNumber,
            recommendedPlateNumber);
    }

    // 使用推荐的车牌号继续后续处理
    var finalPlateNumber = recommendedPlateNumber;

    // 只在车辆上磅期间缓存车牌号（OffScale 状态下不缓存）
    var currentStatus = _statusSubject.Value;
    if (currentStatus == AttendedWeighingStatus.OffScale)
    {
        return;
    }

    // 更新车牌缓存（使用推荐的车牌号）
    _plateNumberCache.AddOrUpdate(
        finalPlateNumber,
        new PlateNumberCacheRecord { Count = 1, LastUpdateTime = DateTime.UtcNow },
        (key, oldValue) => new PlateNumberCacheRecord
            { Count = oldValue.Count + 1, LastUpdateTime = DateTime.UtcNow });

    // 获取最频繁的车牌号并发送通知
    var mostFrequent = GetMostFrequentPlateNumber();
    var message = new PlateNumberChangedMessage(mostFrequent);
    MessageBus.Current.SendMessage(message);
}
```

## 技术细节

### 字符差异计算算法

```csharp
private int CalculateCharDiff(string str1, string str2)
{
    if (string.IsNullOrEmpty(str1) || string.IsNullOrEmpty(str2))
        return Math.Max(str1?.Length ?? 0, str2?.Length ?? 0);
    
    int maxLen = Math.Max(str1.Length, str2.Length);
    int diffCount = 0;
    
    for (int i = 0; i < maxLen; i++)
    {
        char c1 = i < str1.Length ? str1[i] : '\0';
        char c2 = i < str2.Length ? str2[i] : '\0';
        if (c1 != c2) diffCount++;
    }
    
    return diffCount;
}
```

### 线程安全

使用 `ConcurrentQueue<string>` 配合 `volatile` 关键字确保缓存操作的线程安全：

- `ConcurrentQueue` 本身是线程安全的，支持并发遍历和入队操作
- 使用 `volatile` 修饰缓存引用，确保多线程可见性
- 初始化时创建新的队列，然后原子替换引用，避免读操作被阻塞
- 读操作直接遍历当前队列引用，无需加锁

示例代码：

```csharp

public async Task InitializeCacheAsync()

    // 查询数据库并处理数据
```

**优势**：

- 读操作完全无锁，性能最优
- 写操作不阻塞读操作（读操作使用旧的队列引用继续工作）
- 使用标准并发集合，代码简洁

### 错误处理

- 数据库查询失败时记录日志，使用空缓存
- 配置读取失败时使用默认值 0
