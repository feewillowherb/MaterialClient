## 实施步骤

### 步骤 1: 枚举与转换器

- `ScaleType.cs` 添加 `[Description("测试模式")] TestMode = 2`
- `ScaleTypeConverter.cs` 处理 `TestMode` 的显示转换

### 步骤 2: ViewModel 更新

- `SettingsWindowViewModel.cs` 的 `ScaleTypeOptions` 集合添加 `ScaleType.TestMode`

### 步骤 3: 服务层修改

- `TruckScaleWeightService.InitializeAsync()`: 当 `ScaleType == TestMode` 时跳过串口初始化

### 步骤 4: API 端点

- `MinimalWebHostService.cs` 新增 `POST /api/scale/weight` 端点
- 添加 `SetWeightRequest` 请求模型
- 更新根路由端点列表
